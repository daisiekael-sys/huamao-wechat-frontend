# 微信小程序壳（web-view）

> 用微信小程序加载工作台 H5——一套代码同时获得网页端与小程序入口。
> 壳本身不含业务代码，所有界面由 H5 提供。

## 使用前提（缺一不可，均为微信平台规则）

| 前提 | 说明 |
|---|---|
| 企业/非个人主体小程序 | **个人主体不支持 web-view 组件**（微信官方规则） |
| H5 域名已 ICP 备案 | 备案满 24h；备案主体不要求与小程序一致 |
| HTTPS | 不支持 IP + 端口 |
| 业务域名配置 | 小程序后台→开发管理→开发设置→业务域名，下载校验文件放到服务器 |

## 上线步骤

1. **部署 H5**：把工作台部署到已备案的 HTTPS 域名（见 deploy/部署指南.md）
2. **业务域名**：小程序后台下载校验文件 → 放到服务器 `data/wx-verify/` 目录（服务端已支持自动提供 `https://域名/校验文件名.txt`）→ 后台点验证
3. **改 config.js**：把 `h5Url` 换成你的工作台地址
4. **微信开发者工具** 打开本目录 → 填入 AppID → 预览（手机扫码即可真机看）
5. **上传** → 小程序后台「版本管理」→ **设为体验版** → 生成体验二维码
6. 后台「成员管理」把老板的微信号加为**体验成员** → 老板扫码即用，**无需审核**

## 正式发布（可选）

体验版只能体验成员扫码用；要让所有用户搜到/访问，需提交审核（1-7 天）→ 全量发布。

## 常见坑

- web-view 打开白页：90% 是业务域名没配置/没备案/没 HTTPS
- 转账等支付接口需要额外商户号资质（详见主 README 支付章节）
- 个人主体小程序即使写好 web-view 也无法上传生效——别走弯路
